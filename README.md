# beauty-deals

**The Pretty Penny** — a beauty deals site for makeup and skincare markdowns, built on the Pretty Penny design system.

A static site (plain HTML, CSS and JavaScript, no build step): browse deals by category or store, search, sort by discount, end date or price, save favourites (kept in the browser), copy promo codes, and sign up for a weekly email.

Live at https://mrios730.github.io/beauty-deals/

## Run it

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

To publish, enable GitHub Pages for this repo (Settings → Pages → deploy from `main`, root). Pages on the free plan needs the repository to be public.

## Where the deals come from

**Long-term goal: retailer affiliate programs.** Ulta Beauty and Sephora both run affiliate programs. Once approved, they provide product data feeds with current prices, sale prices, product links and images, with permission to use them, and pay a commission on sales made through the site's links. That is the most complete and reliable source, and the one this site should move to. Until then, deals come from two interim sources:

1. **Brand stores (automated)** — `scripts/fetch_brand_deals.py` reads the public product catalog of each brand store listed in `scripts/brands.json` and writes the markdowns it finds to `assets/brand-deals.js`. Prices come straight from the brand, and each card links to the product.
   - Single products whose price was cut are listed first, by percentage off.
   - Sets, kits, bundles and jumbo sizes are compared against the value the brand lists for their contents, not a price they ever sold for, so they go in a **Sets** category as "Set: save $X", never as a percentage off.
   - Free gifts, $0 items and markdowns under 10% are skipped.
2. **Retailer deals (by hand)** — `assets/deals.js` holds Ulta Beauty and Sephora deals gathered from deal-site reports (dealnews, Marie Claire), because both retailers block automated access to their sale pages. Each card links to its report. Deals with an end date hide themselves once it passes.

### Refresh brand-store deals

```sh
python3 scripts/fetch_brand_deals.py
```

Then commit the updated `assets/brand-deals.js`. The script uses only Python's standard library. If a store can't be read it is skipped and reported; if none can be read, the existing file is left unchanged.

### Add a brand

Add an entry to `scripts/brands.json` with the name to show on cards and the store's domain. The store must run on Shopify (it serves `/products.json`); most independent beauty brands do. Re-run the script.

## Files

- `index.html` — page structure
- `assets/prettypenny.css` — Pretty Penny design tokens (colours, type, spacing, radii) as CSS variables
- `assets/styles.css` — site styles, built only from those tokens
- `assets/deals.js` — hand-picked Ulta Beauty and Sephora deals (see the date at the top of the file)
- `assets/brand-deals.js` — brand-store markdowns, generated by `scripts/fetch_brand_deals.py`; don't edit by hand
- `assets/app.js` — filtering, sorting, saving and code copying
- `assets/img/` — product photos and logos for the hand-picked deals (brand-store deals use the brand's own image links)
- `scripts/brands.json` — brand stores to check
- `scripts/fetch_brand_deals.py` — finds markdowns in those stores

## Updating

Edit `assets/deals.js` or re-run the brand script (or change any CSS/JS file), commit, and the site picks it up on the next visit. `index.html` adds a timestamp to every CSS and JS URL, so browsers always load the current files instead of a cached copy. Nothing needs bumping.
